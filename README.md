# ImageVisual

ImageVisual 是一个本地优先的多方法图像对比工具。程序先读取一个数据集文件夹并建立图片索引，之后可以逐步添加不同算法或实验方法的结果文件夹，通过同步切图、缩放、平移和共享 ROI（Region of Interest）比较局部细节。

图片由浏览器直接读取，不会上传到远程服务器。

## 1. 功能概览

- 递归读取数据集文件夹
- 动态添加、重命名、排序、隐藏和删除方法
- 按相对路径或文件名自动匹配图片
- 自动识别 `_result`、`_output`、`_enhanced`、`_restored` 等结果后缀
- 多方法同步切图、缩放和平移
- 多 ROI 新增、切换、删除、独立颜色、移动、四角调整和百分比精确输入
- 所有方法的局部区域实时放大
- 将全部 ROI 按编号批量裁剪为 `_crop1.png`、`_crop2.png` 并保存到本地文件夹
- 在当前全部比较图上绘制自定义颜色和粗细的 ROI 框，并以 `_origin.png` 保存
- 1～4 列对比布局
- 缩略图导航和键盘左右切图
- 本地保存项目设置和目录授权信息
- 导出项目配置 JSON
- 桌面和窄屏响应式布局

推荐使用 PNG、JPEG、WebP、BMP 或 GIF。程序也会扫描 TIFF 文件，但大部分浏览器不能直接显示 TIFF，因此建议先转换为 PNG。

## 2. 技术与运行环境

本项目使用以下技术：

- Node.js `>= 22.13.0`
- React 19
- TypeScript
- vinext / Vite
- 浏览器 File System Access API
- IndexedDB 和 LocalStorage

本地运行不需要数据库、云服务、Python、CUDA 或额外环境变量。

### 推荐环境

| 项目 | 推荐配置 |
| --- | --- |
| 操作系统 | macOS、Windows 10/11 或主流 Linux |
| Node.js | 22.13.0 或更高的 Node 22 版本 |
| 包管理器 | npm；也可使用 pnpm |
| 浏览器 | 最新版 Chrome 或 Microsoft Edge |
| 内存 | 普通数据集至少 4 GB；大量 4K 图片建议 8 GB 以上 |

Chrome 和 Edge 能完整支持目录选择及目录权限恢复。Safari、Firefox 等浏览器会使用兼容的文件夹选择控件，但重新打开页面后通常需要再次选择目录。

## 9. 准备数据集和方法结果

### 简单目录结构

```text
dataset/
├── 0001.png
├── 0002.png
└── 0003.png

method-results/
├── FECNet/
│   ├── 0001.png
│   ├── 0002.png
│   └── 0003.png
└── Retinexformer/
    ├── 0001_result.png
    ├── 0002_result.png
    └── 0003_result.png
```

方法文件夹可以位于任意磁盘位置，不要求拥有相同的父目录。

### 包含子目录的数据集

数据集也可以保留场景子目录：

```text
dataset/
├── scene_01/
│   ├── 0001.png
│   └── 0002.png
└── scene_02/
    └── 0001.png
```

对应方法最好使用相同的相对路径：

```text
FECNet/
├── scene_01/
│   ├── 0001.png
│   └── 0002.png
└── scene_02/
    └── 0001.png
```

相对路径一致时匹配最可靠。如果相对路径不同，程序会退回到文件名匹配。文件名在多个子目录中重复时，应保留一致的子目录结构，避免歧义。

### 匹配规则

程序按照以下顺序匹配：

1. 去除扩展名后，比较完整相对路径。
2. 相对路径不一致时，比较不含扩展名的文件名。
3. 比较文件名时，自动去除 `_result`、`_output`、`_enhanced`、`_restored` 后缀。

例如以下结果都可以匹配数据集中的 `0001.png`：

```text
0001.png
0001.jpg
0001_result.png
0001_output.webp
```

当前版本不会自动移除方法名前缀，例如 `FECNet_0001.png`。这种情况建议在导入前批量重命名为 `0001.png`，或者保持与数据集一致的相对路径和文件名。

## 10. 正确使用应用

### 第一步：选择数据集

1. 打开应用首页。
2. 点击“选择数据集文件夹”。
3. 在浏览器权限窗口中选择数据集目录。
4. 点击允许访问。
5. 等待应用完成图片扫描。

数据集决定图片总数、名称和浏览顺序。更换数据集时，当前添加的方法会被清空，避免不同数据集之间错误匹配。

### 第二步：添加方法

1. 在左侧“方法”区域点击“添加方法文件夹”。
2. 选择某个方法的结果目录。
3. 等待程序自动匹配。
4. 查看方法名称下方的匹配数量，例如 `492/500 已匹配`。
5. 根据需要继续添加其他方法。

方法名称默认使用文件夹名称。可以直接点击方法名称进行编辑。

每个方法右侧提供：

- 上移和下移
- 显示或隐藏
- 删除

某个方法缺少当前图片时，只会在该方法面板中显示缺失提示，不影响其他方法。

### 第三步：同步查看图片

- 点击顶部左右按钮切换图片。
- 点击底部缩略图直接跳转。
- 使用键盘 `←` 和 `→` 切换图片。
- 使用鼠标滚轮缩放。
- 切换到“拖动”工具后拖拽图片。
- 开启“同步视图”后，所有方法共享缩放和平移状态。
- 点击“适应窗口”恢复默认显示。
- 按数字键 `0` 也可以恢复同步视图。

关闭“同步视图”后，每个方法可以拥有独立的缩放和平移位置。

### 第四步：调节 ROI

1. 选择顶部“选区”工具。
2. 在右侧“选区管理”中点击“添加选区”，创建新的编号选区；程序会自动循环分配不同颜色。
3. 点击“选区 1”“选区 2”等按钮，切换当前编辑选区；也可以直接点击图片中的编号框。
4. 在任意图片空白位置按住鼠标并拖动，重新绘制当前选区。
5. 拖动选区内部可以移动当前选区。
6. 拖动当前选区的四个圆形角点可以调整大小。
7. 在右侧输入 X、Y、宽和高，可以对当前选区进行百分比精确调整。
8. 点击“删除当前”可以删除活动选区；程序始终至少保留一个选区。

全部 ROI 会同时显示在所有比较图片上，并使用 `ROI 1`、`ROI 2` 等编号和不同颜色。当前活动选区使用实线和调整手柄，其他选区使用虚线。ROI 使用归一化坐标，因此不同分辨率的方法结果会显示相同的相对区域。

右侧细节预览显示当前活动选区。“细节放大”滑块用于进一步收窄活动选区中心区域，范围为 `1×` 到 `4×`。切换选区后，所有方法的预览会实时更新。

### 第五步：保存 ROI 裁剪

1. 添加并调整全部需要保存的 ROI。
2. 点击右侧细节面板顶部的“保存全部裁剪”。
3. 在 Chrome 或 Edge 的目录选择窗口中选择输出文件夹。
4. 程序会将数据集原图和所有当前可见、且已匹配的方法结果分别裁剪并写入该文件夹。

程序会对每一张当前比较图片依次裁剪全部选区。裁剪始终使用各 ROI 的完整范围，不受右侧“细节放大”倍数影响。输出统一转换为 PNG。

只有一张可用比较图片并且包含两个选区时，文件名为：

```text
0001_crop1.png
0001_crop2.png
```

同时保存数据集和多个方法时，文件名中会加入方法名称和选区编号：

```text
0001_LOL-v2_crop1.png
0001_LOL-v2_crop2.png
0001_FECNet_crop1.png
0001_FECNet_crop2.png
0001_Retinexformer_crop1.png
0001_Retinexformer_crop2.png
```

删除或调整选区顺序后，导出编号会按照界面中当前的 `选区 1`、`选区 2` 顺序重新生成。

文件名中不允许出现的系统字符会自动替换为下划线。如果目标文件夹中已经存在同名文件，当前版本会覆盖该文件。

Safari、Firefox 等不支持目录写入的浏览器会退化为普通下载，由浏览器将每一张裁剪图片保存到默认下载目录。批量下载时浏览器可能询问是否允许下载多个文件。

### 第六步：保存带选定框的全部比较图

1. 添加并调整全部 ROI。
2. 确认左侧需要导出的方法处于显示状态；缺失当前图片的方法会被自动跳过。
3. 在右侧“比较图选定框”区域点击颜色控件，为当前活动选区设置颜色。切换到其他选区后可以分别设置不同颜色。
4. 使用“线条粗细”滑块设置框线宽度，范围为 `1px`～`32px`。这里的像素值对应每张比较图自身的像素，不是网页显示像素。
5. 查看控件下方的线条样式预览。
6. 点击“保存全部带选定框的比较图”。
7. 在 Chrome 或 Edge 中选择本地输出文件夹。

程序会把全部 ROI 按各自颜色画在当前数据集图片以及所有可见且已匹配的方法图片上，统一输出为 PNG。导出的 `_origin.png` 只保留彩色选择框，不绘制 `1`、`2` 等文字编号；界面中的 ROI 编号和裁剪文件编号保持不变。其方法集合与“保存全部裁剪”完全一致。

例如“保存裁剪”生成：

```text
0001_LOL-v2_crop1.png
0001_LOL-v2_crop2.png
0001_FECNet_crop1.png
0001_FECNet_crop2.png
0001_Retinexformer_crop1.png
0001_Retinexformer_crop2.png
```

对应的选定框图片将生成：

```text
0001_LOL-v2_origin.png
0001_FECNet_origin.png
0001_Retinexformer_origin.png
```

一张 `_origin.png` 中包含该方法图片上的全部彩色选择框，但框上不显示编号。框的颜色和位置仍与界面中的选区一一对应；界面的选区 1 对应 `_crop1.png`，选区 2 对应 `_crop2.png`。当当前比较组只有数据集图片时，输出名称为 `0001_origin.png`，对应裁剪为 `0001_crop1.png`、`0001_crop2.png` 等。

每张 `_origin.png` 保持对应比较图的完整宽高，不进行裁剪或缩放。选定框接触图片边缘时，程序会将框线向内偏移半个线宽，避免框线被画布裁掉。如果目标文件夹中已经存在同名文件，当前版本会覆盖该文件。

在不支持目录写入的浏览器中，该操作会退化为多文件普通下载。

## 11. 项目配置和本地数据

应用使用两种浏览器本地存储：

- LocalStorage：保存数据集名称、方法名称、排序、显示状态、当前图片、全部 ROI、当前活动选区和界面设置。
- IndexedDB：保存浏览器授予的目录句柄。

重新打开应用时，可以点击“恢复上次项目”。浏览器可能要求重新确认数据集和方法目录的读取权限。

以下操作会导致项目恢复信息消失：

- 清除该站点的浏览器数据
- 使用隐私或无痕窗口后关闭窗口
- 更换浏览器或浏览器用户配置
- 将应用切换到不同的域名或端口

“导出配置”会生成 `.imagevisual.json` 文件，其中包含界面配置和目录元数据，但不会包含图片本身。当前初始版本尚未提供配置文件导入按钮；导出的文件主要用于记录、备份和后续版本迁移。即使后续导入到另一台电脑，由于浏览器安全限制，仍然需要重新选择图片目录。

## 12. 浏览器权限配置

首次选择目录时，请允许网站读取所选文件夹。应用只会获得用户主动选择的目录权限，不能读取其他目录。

如果误点拒绝：

1. 点击浏览器地址栏左侧的站点权限图标。
2. 查看文件或文件夹相关权限。
3. 恢复允许状态，或者刷新页面后重新选择目录。

不要直接以 `file://` 方式打开源代码文件。应用必须通过 `npm run dev` 或 `npm run start` 提供的 `http://localhost` 地址运行，否则目录权限、模块加载和项目恢复功能可能失效。

## 13. 常见问题

### `node: command not found`

Node.js 未安装，或终端尚未刷新环境变量。安装 Node 22 后关闭并重新打开终端，再运行：

```bash
node --version
```

### Node 版本过低

如果安装依赖时出现引擎版本错误，请升级到 Node `22.13.0` 或更高版本：

```bash
nvm install 22
nvm use 22
```

### 依赖安装失败

先确认网络能够访问 npm 软件包仓库，然后重试：

```bash
npm install
```

如果已有不完整的 `node_modules`，可以删除项目根目录中的 `node_modules`，然后运行：

```bash
npm ci
```

不要删除 `app/`、`package.json` 或自己的图片数据目录。

### 端口被占用

使用其他端口启动：

```bash
npm run dev -- --port 3001
```

### 选择文件夹后没有图片

检查：

- 文件扩展名是否属于支持范围
- 图片是否损坏
- 图片是否位于所选目录或其子目录中
- 浏览器是否具有读取目录的权限
- TIFF 是否因为浏览器不支持而无法显示

### 方法匹配数量为 0

检查方法图片和数据集图片是否具有相同文件名。特别注意：

- 是否存在额外前缀
- 是否使用完全不同的编号格式
- 子目录中是否有重复文件名
- 文件名是否包含空格或其他额外字符

推荐让数据集和方法结果使用完全相同的相对路径。

### 刷新后无法恢复项目

使用 Chrome 或 Edge，并点击“恢复上次项目”重新授权目录。如果浏览器数据已被清除，需要重新选择数据集并重新添加方法。

### 大量图片导致页面变慢

- 优先使用压缩后的 PNG、JPEG 或 WebP
- 避免同时添加大量超高分辨率方法结果
- 关闭暂时不需要的方法
- 将 TIFF 转换为 PNG
- 关闭其他占用大量内存的浏览器标签页
